# Desvelo JS

Curso intensivo de JavaScript para una noche, en una sola página (`index.html`).

- 12 misiones: variables, funciones, decisiones, bucles, arrays, objetos, métodos de array, closures, clases, asincronía, DOM y un jefe final.
- Ejemplos editables que se ejecutan en el navegador (Ctrl + Enter).
- Predicciones ("¿qué imprime?") y 31 desafíos con pruebas automáticas.
- El código corre aislado en un Web Worker (o un iframe con sandbox para el DOM) y se corta solo a los 5 segundos.
- Progreso, XP y código guardados en `localStorage`.

Abrí `index.html` en cualquier navegador. El tutor con IA solo aparece cuando la página se abre como Artifact dentro de Claude.
