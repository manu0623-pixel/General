# Desvelo JS

Curso de JavaScript desde cero, en una sola página (`index.html`).

- **Fundamentos (misiones 0–8):** primeros pasos, variables, números y textos, funciones, decisiones, bucles, listas, objetos y una primera página web (DOM).
- **Para seguir (misiones 9–13):** métodos de array, closures, clases, asincronía y un jefe final.
- Visualizador **paso a paso**: muestra qué línea se ejecuta y qué guarda cada variable.
- **"¿Qué hace cada línea?"** en los ejemplos, **glosario** (las palabras técnicas se tocan para ver su definición) y un **resumen** por misión.
- Ejercicios **"Tu turno"** después de cada idea y desafíos con pruebas automáticas.
- El código corre aislado en un Web Worker (o un iframe con sandbox para el DOM) y se corta solo a los 5 segundos.
- Progreso, XP y código guardados en `localStorage`.

Abrí `index.html` en cualquier navegador. El tutor con IA solo aparece cuando la página se abre como Artifact dentro de Claude.
